# guest-register-rules

宿泊者名簿（Tally版）の「定期報告CSV」テンプレートが読み込むルール表です。

- 利用者のスプレッドシートは `IMPORTDATA` でこのリポジトリの `rules.csv`（raw）を読み込み、その内容に従って ical の照合・国籍の集計・定期報告の1行を作ります。
- 利用者のデータはこのリポジトリには一切送られません（読み込みは一方向）。

## rules.csv
`section,key,value` の3列。値にカンマと `"` は使わない。複数の値は `|` で区切る。

| section | 内容 |
|---|---|
| meta | ルール表の版 |
| ical | Airbnb ical の読み方（予定の区切り・日付の目印・予約番号の形） |
| tally | Tally の回答シートの列名 |
| report | 国籍22区分の順番・報告月・締め日 |
| country | Tally の国名の選択肢 → 22区分 |
| notice | 利用者の画面に出すお知らせ |

## 変更するとき
全利用者のシートに数分で反映されます。変更前に必ず検査を通すこと。
